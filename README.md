##  Jokempô
🎮 Jokempô (Pedra, Papel e Tesoura) — Android Nativo
Um aplicativo nativo para Android desenvolvido em Kotlin no qual o usuário disputa partidas clássicas de Pedra, Papel e Tesoura contra a CPU em tempo real.

🚀 Sobre o Projeto
O objetivo do projeto é demonstrar a aplicação prática de componentes essenciais da interface gráfica do Android e a implementação da lógica do jogo de forma simples, responsiva e performática.

🛠️ Tecnologias e Componentes Utilizados
Language: Kotlin

UI Components:
- ConstraintLayout: Para garantir uma interface totalmente responsiva e adaptável a diferentes tamanhos de tela.
- ImageView: Utilizado para exibir dinamicamente as opções do jogador e a jogada sorteada pela maquina.
- TextView: Responsável pela renderização do status do jogo (vitória, derrota ou empate) e atualização em tempo real.

🎯 Funcionalidades
- Jogada do Usuário: Seleção interativa da opção desejada através da interface.
- Jogada da CPU: Sorteio randômico da jogada da máquina.
- Lógica de Decisão: Validação automática das regras do jogo para determinar o resultado.
- Feedback Dinâmico: Atualização visual imediata das imagens e texto de resultado na tela.
